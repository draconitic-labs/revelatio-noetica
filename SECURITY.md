# Security

Revelatio Noetica is a local desktop app. It makes no network connections and has no accounts.
It does read files you give it: saved scenes, scene links and its own session file.

To report a problem, such as a crafted scene file that crashes the app or writes somewhere it
should not, use "Report a vulnerability" on the repository's Security tab if it is available.
Otherwise open an issue that describes the affected area without exploit details, and ask for a
private way to send them.
